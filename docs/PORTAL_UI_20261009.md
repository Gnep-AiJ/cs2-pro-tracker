# 综合信息站 UI 调整

本轮依据用户九项反馈，在现有 React/Vinext 项目内调整；没有部署。

## 设计

参考 frontend-design SKILL 与用户 FACEIT 截图。保留比赛阅读主线，改变所有区域相同灰色卡片的处理。基础色 #09090a、文字 #f2f2f3；FACEIT 橙 #ff650a、赛事蓝 #459ddd、Valve 金 #e9b853、动态紫 #a777ed。绿色只标示领先或胜利。沿用现有字体，表格数字等宽对齐；主标题与辅助文字保持清楚层次。

- 主导航：FACEIT → 赛事 → 动态；取消底部跳转，保留全站“联系与打赏”。Logo 与内容链接保持当前语言。
- FACEIT：顶部同一行提供榜单、对比、查找选手。官方排名为默认页，以表格展示排名、选手、国家、等级、ELO，只筛赛区和国家。
- 收录选手 TOP 10：从核验账号目录读取真实 FACEIT 档案与 CS2 生涯统计，按 ELO / 场次 / 胜率重算前十。每次最多六个并发请求；完整结果缓存一小时，部分结果不进入公共缓存。不把职业选手榜当作全球官方榜。
- 对比：按显示精度标注“领先”或“持平”，有正负值时按数值比较。图数、累计击杀、累计死亡不评胜负，避免样本量不同导致误导。不生成综合评分。
- 档案：橙色身份背景、真实 FACEIT 等级、国别和区域，摘要指标分色。比赛记录仍优先。
- 赛事：选择赛事旁提供金色 Valve 积分按钮，打开独立全宽排名表。目录按进行中、即将开始、近半年赛果分组，搜索跨组有效。
- 动态：独立资讯版面、来源筛选、原文直达；英文选择优先显示原始标题。

## 赛事目录检查

2026-10-09 只读检查三个 PandaScore 目录，均为 HTTP 200：running 1 个阶段，upcoming 3 个阶段，past 返回最新 100 个阶段（总数 792）。未来三个阶段同属 Thunderpick，不是三个赛事。

旧代码将历史范围限制为 45 天，合并系列并排除低级别/资格赛后得到五项。数量与部署状态无关。本轮将历史窗口扩为 180 天，未来仍为 120 天；S/A、主赛事、精确系列 ID、缓存和额度策略保留。上游未发布的未来赛事不伪造填入。

FACEIT 公开排行榜响应使用 `game_skill_level`；不是 `skill_level`。已按实际响应修正。官方榜单不返回头像时使用姓名缩写，不复制未知头像。

## 验证

构建与 74 项测试通过，TypeScript 通过；lint 0 错误、10 条既有警告。56 个发布文件凭据扫描通过。浏览器验证官方排名、动态 TOP 10、逐项领先/平手、顶部导航、赛事选择及 Valve 弹窗；360px FACEIT 和动态页面无横向溢出。证据保存在 `outputs/portal-20261009/`。既有原始联系和打赏二维码保持不变；未部署。

本地刷新已实际显示 14 项 PandaScore 赛事（进行中 1、未来 1、历史 12）。请求超时由 6 秒调整至 12 秒，修复较慢目录读取时过早切回存档。HLTV 日历独立展示 10 月 7 日存档，含 11 项赛事，原文链接打开；不宣称实时比分。

- 查找窗口展示战队及阵容，不再将第一名选手作为整支战队的摘要。全站 FACEIT 搜索独立于十支收录战队和 TOP10 榜单。
