## Product and data

Events first; FACEIT second. Four compact tabs, folded source/roster details, logos, player portraits, real comparison bars, bilingual selection and mobile layout. Individual comparison requires selection of two distinct stable identities. Search accepts partial names, case, leet spelling and small typing errors.

Production readback: 11 HLTV Big/Featured events; EPL 33 fixtures/results and 80 source-listed roster players; 10 players with available Ensigame statistics. ENSI /10 is its own score, not HLTV Rating. Full-event individual coverage is not available. Future-event performance is withheld. Valve requirements and dated standings are separately identified; the event list is not a Tier 1 certification.

Calendar refresh: hourly per live Worker isolate; selected event observations refresh on request behind a five-minute edge cache. Verified dated snapshots preserve usability when public sources block requests. The current product path does not require PandaScore credentials. Public source structure changes and provider coverage remain external dependencies. There is no deployed scheduled persistence job; `npm run data:events` updates the bundled durable snapshot before a subsequent release.

Workers AI uses the existing production AI binding and server-observed facts. Numeric, language, sample and event-unit/terminology checks retain a deterministic data summary when output is rejected. A production AI terminology error found during acceptance was fixed and covered by regression cases. AI does not determine ratings or rankings.
