# 界面收缩与逻辑修复 — 2026-10-09

用户反馈界面复杂、技术说明过多，并授权删除功能以减少混乱。本次取代此前五个 FACEIT 工具弹窗与赛事多栏导航方向。修改仅在本地，不包含部署。

## 最终范围

- FACEIT：精选对局、近期列表、查找和筛选；榜单、选手对比为次级入口。同局分析和 AI 入口移除。精选对局不在近期列表重复展示。
- 赛事：当前赛事标题和切换入口、简短日期/来源、赛程赛果；参赛阵容与 Valve 积分折叠。真实个人成绩达到样本门槛时才显示二级成绩/对比入口。
- 档案：左侧身份，右侧有效摘要与默认展开的对局记录；曲线、地图、生涯折叠。没有数据的指标、控件和章节不显示。
- 设计学习用户提供的 FACEIT 截图：深色中性背景、橙色选中状态、比分层级、清楚的表头与独立选手身份。没有加入登录、聊天或社交等额外功能。
- 删除面向用户的技术处理说明；保留必要的来源、日期、历史状态和统计场次。

## 逻辑修复

1. 赛事空击杀数不能按 0 计算 K/D；对比只展示双方都具备的数值。
2. FACEIT 对比与榜单统一使用有效记录的总击杀/总死亡计算 K/D；不推算 Rating/Swing。
3. 房间元数据省略比分、地图或部分阵容时保留历史有效字段；真实新值和 0 可以更新旧值，错误房间 ID 不合并。
4. 完全空白的记分板列、半场信息、详细统计不显示；保留真实 0 和负 Swing。逐图记分板分别显示。
5. 图表只提供有数值的指标，并默认选中可用指标；空 ADR 不遮挡实际 K/R。
6. 对局与工具弹窗互斥；URL 同时包含房间和工具参数时先显示房间。固定榜单中的对比跳转统一对比界面。
7. 档案更新时间使用当前响应时间；旧高级统计的存档日期放在“更多统计”内部，避免把当前对局标成旧数据。
